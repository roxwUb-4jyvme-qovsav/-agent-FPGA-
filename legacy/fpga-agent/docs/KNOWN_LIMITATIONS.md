# 已知限制

- 本仓库不是比赛提交仓库；修改不会自动同步或部署。不得把比赛令牌和公网地址写入开发应用。
- 未提供前端、用户账户、多租户隔离、CORS 配置和重启后的任务恢复。建议增加独立业务后端代理，不让浏览器接触令牌。
- Jobs 当前为有容量上限的内存队列，求解串行；网络结果不明确时不能自动重复投题。关闭页面也不会取消任务。
- 内部编译/综合与有限语义检查不证明完整功能正确，必须区分生成成功、内部工具通过和独立 L1/L2/L3。
- 公共语义检查只支持有限结构，不是通用 Verilog 证明器；未知结构保留不确定状态。
- 现有路径检查不能证明恶意同用户并发改写、junction 或系统级隔离安全。
- 2026-10-27 的开发集和连续服务、公网检查是历史记录，不保证开发者机器当前可运行或官方隐藏题成绩。
- 最终镜像冷启动与官方隔离/隐藏题结果不在本次上传中实测。源码一致性检查不能代替 GPU、许可或 EDA 运行。
- 固定 Skill、官方 Baseline、运行预算及模型权重锁不因中文文档更新而改变；许可证按上游分别保留，未擅自为整个工程添加新许可证。
