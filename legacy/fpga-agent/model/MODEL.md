# 模型来源与有效配置

- 模型：最终 RL 版 CodeV-R1-RL-Qwen-7B，不是 Distill 蒸馏版。
- 公开权重：https://huggingface.co/zhuyaoyu/CodeV-R1-RL-Qwen-7B
- 固定 revision：286cf433f596f1b8525529c1163eb81c19425c22。
- model/assets_lock.json 保留配置、分词器、索引和四个权重分片的大小及 SHA256；模型权重不上传 Git。
- 历史验证环境：AMD 单卡、BF16、TP1、32768 上下文、max sequences=1、eager、显存预留 0.55；别名 codev-r1-7b，本地端口 8002。历史后端 vLLM 0.27.1.dev5+gf46a9dfe2.d20260827，不代表任意开发机当前已安装。

团队没有对权重训练、量化或增加辅助模型。部署前预置完整权重及上游许可证，按锁核验；默认模型路径 /opt/rtl-agent/model/weights，可通过 MODEL_PATH 指向实际预置目录。运行期禁止自动联网下载。
