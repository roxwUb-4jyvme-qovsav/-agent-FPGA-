## 协作约定

- `main` 保留可解释的快照和经过审查的修改；每个功能使用独立分支，通过 PR 合并。
- A 负责业务后端和模型适配；B 负责 RTL 与独立验证；C 负责交互、需求确认和演示集成。每项至少由另一人复核。
- 先冻结模块接口、需求版本、目标板卡和验收标准，再写代码。三人不是同时修改 `feedback_agent_v24.py`。
- API Key、赛事令牌、模型权重、原始敏感提示、板卡私有资料不提交。前端不持有模型 Key。
- 新 API 模式作为显式的新版本开发，保留旧本地模式作为对照；不冒用原历史成绩和来源锁。
- 仓库目前为私有。需由仓库所有者添加另外两人的 GitHub 账号；本轮没有修改成员权限或分支保护。
